# Lunara-jewellery-website-development-project
Responsive Jewellery E-commerce Website | HTML, CSS, JavaScript

## Features
- Responsive layout for desktop, tablet and mobile
- Product catalogue with category filters and sorting
- Product search
- Product detail dialog
- Shopping bag with add/remove and quantity controls
- Live subtotal calculation
- Newsletter form interaction
- Mobile navigation

## Run locally
No build tools are required. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Technologies
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- Vanilla JavaScript (DOM events, array methods, state management)
